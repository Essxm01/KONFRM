## 2. Mandatory Guardrails & Security Policies

1. **Zero Binary Execution:**
   - Upstream repository contains binary hooks (`.codex/hooks.json`, rust binaries). These are **strictly prohibited** in KONFRM. No automated binary or shell hooks may be registered or executed.
2. **Token-Grounded Reviews:**
   - Contrast, spacing, and typographic critiques must evaluate against actual KONFRM tokens in `DESIGN_SYSTEM/TOKENS/`, NOT generic web defaults or arbitrary hex values.
3. **No Decorative Clutter:**
   - Gamification, confetti animations, bouncy cartoon physics, and decorative badges are prohibited on core screens.
4. **RTL Native Evaluation:**
   - Critiques must assess visual balance from an Arabic-first, RTL reading perspective (right-to-left flow, mirrored padding, and Western Arabic numerals `0-9`).

## 3. How to Apply

Agents should read and apply the relevant playbook directly from `playbooks/`:
- To polish an existing screen layout: Read `playbooks/polish.md` and check against KONFRM spacing tokens.
- To conduct a design review: Read `playbooks/critique.md` and evaluate typography and hierarchy.
- To simplify an overloaded screen: Read `playbooks/distill.md`.
