# Source research and boundaries (2026-10-08)

Repositories were inspected as read-only references; copied executable code from upstream is **not** included.

- https://github.com/ayghri/i-have-adhd — MIT; concise action-first response, cap active list, persistence-in-session, explicit safe exceptions. Provides **output ergonomics** but no complete KONFRM backlog governance.
- https://github.com/jdpolasky/chief-of-staff-2 — MIT; Markdown as durable source; brief router + session snapshot; avoid building large monitoring machinery. Provides **memory architecture discipline**.
- https://github.com/UditAkhourii/adhd — MIT; parallel divergent ideation for genuinely open high-stakes problems only; avoid use on every new thought to protect focus and cost.
- https://github.com/adrianwedd/ADHDo — larger app with state gathering / nudge scheduling; borrowed only concept of context-sensitive nonintrusive interventions; health/medication/music/location/system monitoring explicitly out-of-scope.
- https://github.com/mrseth01/awesome-adhd — resource list; no code imported, clinical/health advice excluded.
- https://github.com/XargsUK/awesome-adhd — resource directory; no code imported, third-party tracker dependencies excluded.

**One governing observation:** do not claim this skill is a medical tool or diagnoses ADHD. Model's session memory is not durable. GitHub versioned records + verified runtime checks provide operational continuity after integration.
