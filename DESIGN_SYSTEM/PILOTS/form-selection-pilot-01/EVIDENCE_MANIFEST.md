## Summary of Empirical Findings

1. **Field Visual Strategy Winner:** **Outline-Led Baseline (Crisp 1px Neutral Outline on Pure White)** provides the cleanest solution across both Customer and Owner mobile roles. The Web pilot candidate outline (`#8E8E93`, 3.26:1 contrast against `#FFFFFF`, 3.12:1 against `#F8FAFC`) ensures accessible non-text component boundary demarcation on light-first surfaces without producing visual "box soup", and avoids muddy gray fills inside cards. Any multi-field grouped containers shown in the pilot are **PILOT COMPOSITION ONLY / PHASE 4E STRUCTURAL AUTHORITY DEFERRED**.
2. **Radius Finding (8px Retained):** **8px** is retained as the recommended candidate based strictly on visual balance: it provides gentle visual softening for larger 48px input containers compared to 6px, avoids the generic bubbly curvature of 10px, and harmonizes with the 6px Primary Button without copying button geometry. 6px remains an architectural alternative if the Founder prefers exact geometric symmetry.
3. **Focus Treatment:** **Semantic Restrained Interaction-Accent Emphasis** is markedly superior to pure black focus borders because pure black competes directly with the provisional `#000000` Primary CTA button. The Web pilot rendering reference is **1px accent field border + 3px outer halo** (candidate `#276EF1`); exact native token, ring/halo widths, and platform implementation remain **Web pilot rendering reference only / open native validation (Phase 4I)**.
4. **Bidi & Accessibility:** Explicit `dir="ltr"` wrappers on phone and email fields prevent cursor jumping and reverse-hyphen distortion in Arabic context. Text-associated errors with alert icons pass controlled pilot inspection without color-only dependence (exact native assistive acceptance deferred to platform gates). Visible control geometry is distinct from platform interactive target bounds (iOS 44pt / Android 48dp guidance).
5. **Selection Controls:** Checkbox is evidenced in Owner notification settings. Toggle has zero current product evidence and is classified as deferred future capability.
