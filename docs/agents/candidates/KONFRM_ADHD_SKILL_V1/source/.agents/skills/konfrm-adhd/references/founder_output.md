# Minimal cognitive-load reporting

## Default output (Arabic Egyptian)
**دلوقتي:** [what is proven NOW + current phase/PR].
**الفكرة:** [capture receipt ID + Candidate/Approved/Deferred + when/why].
**الخطوة التالية:** [one concrete move].

Do not give a full roadmap unless explicitly asked. On complex analyses, use sections and a final priority order. Never force a 5-item limit where it would omit requested completeness; group items instead. Do not state artificial precise time estimates. Avoid medical descriptors, shaming, coercion or guilt. Celebrate verified progress by identifying evidence, not flattery.

## Founder commands (natural language)
- «احفظ الفكرة دي» → capture record with explicit confirmation of persisted/not persisted.
- «قيّم الفكرة» → focused benefit/dependency/conflict assessment, ask for approval before scheduling.
- «اعتمدها وخليها لوقتها» → mark Founder decision and queue slot, preserve NOW.
- «فين إحنا؟» → check stored NOW against current GitHub HEAD; identify differences.
- «نبدأ حاجة تانية» → switching-cost gate and safe transition, no passive resistance.
- «إيه اللي اتقفل؟» → closure evidence, distinguish PR closed vs verified done.
