# Integration & authority boundaries

## Skills routing
This is an always-available, lightweight **process overlay**, NOT an eighth domain brain. `konfrm-design` owns UX/design; `konfrm-flutter` owns implementation; `konfrm-quality` owns verification; future `konfrm-product` owns product interpretation only after approved activation. ADHD SKILL never hands off code or makes domain verdicts.

## Safe activation proposal
Do NOT edit `AGENTS.md`, `.agents/SKILL_MANIFEST.yaml`, `.agents/SKILL_ROUTER.md`, `.agents/CONTEXT_MAP.yaml` without a separate isolated integration PR. Once approved, add only a concise discoverability link and one process-overlay registration; preserve existing active/deferred brain counts and shape. Trigger on `new idea`, `prioritization`, `plan switch`, `resume`, `roadmap placement`, `Founder handoff` rather than every code-edit event.
