# Pinned Pilot Typography Provenance Record — Cairo Typography Foundation Validation 01

This directory contains the pinned font asset used exclusively for deterministic typography-sensitive layout measurements, visual evidence generation, and reproducibility in **Cairo Typography Foundation Validation 01 (Controlled Design Pilot)**.

> [!NOTE]
> **GOVERNANCE NOTICE: PILOT REPRODUCIBILITY ASSET ONLY**  
> Pinning Cairo for Typography Foundation Validation 01 reproducibility does **not** promote Cairo to final mobile Canon or declare native Flutter typography implementation. It ensures that web-based frame-width (360px, 390px, 430px), line-wrapping, and text-scaling simulations (100%, 125%, 150%, 200%) run against identical, uncorrupted font metrics across all host and CI environments without network or system font dependencies.
