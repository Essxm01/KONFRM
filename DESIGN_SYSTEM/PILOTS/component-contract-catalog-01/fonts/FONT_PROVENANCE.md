# Pinned Pilot Typography Provenance Record

This directory contains the pinned font asset used exclusively for deterministic typography-sensitive layout measurements and visual evidence reproducibility in **Controlled Primitive Pilot 01**.

> [!NOTE]
> **GOVERNANCE NOTICE: PILOT REPRODUCIBILITY ASSET ONLY**
> Pinning Cairo for Pilot 01 reproducibility does **not** promote Cairo to a new mobile Canon token or declare native Flutter typography implementation. It ensures that web-based frame-width, wrapping, and text-scaling simulations run against identical font metrics across all host environments.
