## Classification Legend
- **VERIFIED_DETERMINISTIC_TEST:** Full invariant enforced and proven offline by automated test assertions.
- **PARTIAL_DETERMINISTIC_TEST:** Structural/schema invariant proven offline, but operational boundary (e.g. live API, distributed multi-machine coordination) requires separate procedural safeguards.
- **LOGIC_EVALUATED_OFFLINE / NATIVE_RUNTIME_NOT_VERIFIED:** Business rules, parsing, deduplication, and gates evaluated offline via isolated test harness (`pilot-konfrm-focus.mjs`). Native Antigravity runtime execution remains NOT_VERIFIED because the skill is an uninstalled candidate in PR #106 and live installation in `.agents/skills/` is forbidden without explicit Founder approval.
- **PENDING_INTEGRATION_PILOT:** Superseded by offline evaluation and live status recording above.
